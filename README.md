# ResumeIQ 📄🤖

ResumeIQ is an AI-powered resume analysis web application designed to help job seekers evaluate and improve their resumes for better job opportunities.

## 🚀 Features

- 📄 Resume upload and processing
- 🤖 AI-powered resume analysis
- 🎯 Resume relevance and job-readiness evaluation
- 🔍 ATS-focused resume analysis
- 💡 Personalized resume improvement suggestions
- 📊 Structured analysis results
- 🌐 Simple and responsive web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Jinja2
- AI-powered text analysis
- Git & GitHub

## ⚙️ How It Works

1. Upload your resume.
2. ResumeIQ processes the submitted resume.
3. The application analyzes the resume content.
4. The resume is evaluated for job-readiness and ATS compatibility.
5. Analysis results are displayed in a structured format.
6. Users receive recommendations for improving their resume.

## 💻 Installation

Clone the repository:

    git clone https://github.com/Cash-194/resumeiq.git

Navigate to the project directory:

    cd resumeiq

Create a virtual environment:

    python -m venv .venv

Activate the virtual environment on Windows:

    .venv\Scripts\activate

Install dependencies:

    pip install -r requirements.txt

Run the application:

    python app.py

Open your browser and visit:

    http://127.0.0.1:5000

## 🎯 Purpose

ResumeIQ was developed to demonstrate the practical application of Python, Flask, AI-based text analysis, and web application development to solve a real-world problem faced by job seekers.
